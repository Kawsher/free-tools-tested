# free-tools-tested

Code from Kawsher Mahbub videos: free and underrated tech tools, tested on real tasks.

Free tools. Real tests. No hype.

## How to use this repo

Find the video you watched, then open its folder. Each folder has its own README with what the tool does, what you need, and how to run it.

Shorts do not have separate code folders. Code follows long videos only. The table below shows both numbers, so you can find a tool either way.

## Rules for every folder

1. No API keys, tokens, or personal file paths in the code. Use a placeholder like YOUR_API_KEY.
2. Credit the original author if a notebook or tool is not yours. Link the original in that folder's README.
3. Code is added before the video publishes, and the link in the video description points to that folder.
4. If a tool changes its free limit, the folder README is updated. The video stays as a record of the test on that date.
